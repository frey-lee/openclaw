# Update plan

Update project planning documents by moving completed work to COMPLETED.md and keeping PLANNING.md and TASKS.md focused on current and future work only.

## Process Overview
1. **Move completed items to COMPLETED.md**: Transfer all completed plans and tasks with full details
2. **Clean PLANNING.md**: Remove completed sections, keep only active/future plans  
3. **Clean TASKS.md**: Remove completed tasks, keep only pending/in-progress tasks

## Specific Instructions

### For AI_workdir/COMPLETED.md
- **ADD** detailed summaries of all completed plans from PLANNING.md
- **ADD** completed tasks from TASKS.md with their outcomes
- **MAINTAIN** chronological order (most recent completions first)
- **INCLUDE** technical details, metrics, and impact of completed work

### For AI_workdir/PLANNING.md  
- **REMOVE** all completed plans and sections marked as ✅, "COMPLETED", or "PRODUCTION READY"
- **KEEP** only current project phase, active plans, and immediate next actions
- **FOCUS** on what needs to be done next, not what was already accomplished  
- **MAINTAIN** a concise, forward-looking document for ongoing work
- If project is complete, create a brief "Project Complete" status and list only future enhancement opportunities

### For AI_workdir/TASKS.md
- **REMOVE** all tasks marked [OK], [✅], "COMPLETED", or with completed status
- **KEEP** only tasks marked [ ] (pending) or actively in progress
- **ADD** new tasks based on current project needs and next steps
- **ORGANIZE** remaining tasks by priority (High/Medium/Low)
- If no active tasks remain, create "All Tasks Complete" summary and list only optional future enhancements

## Key Principle
**COMPLETED.md = Archive of finished work**  
**PLANNING.md = Current roadmap (active work only)**  
**TASKS.md = Active work items (pending/in-progress only)**

The goal is to maintain clean, actionable planning documents that focus on what still needs to be done, while preserving the history of completed work in COMPLETED.md for reference.
