# Update tasks

Update AI_workdir/TASKS.md to maintain a clean, actionable task list focused on pending and in-progress work only.

## Process Overview
1. **Move completed tasks to COMPLETED.md**: Archive finished tasks with their outcomes
2. **Clean TASKS.md**: Remove completed tasks, keep only active work
3. **Add new tasks**: Create tasks based on current project needs and PLANNING.md

## Specific Instructions

### For AI_workdir/TASKS.md
- **REMOVE** all tasks marked [OK], [✅], "COMPLETED", or with completed status
- **KEEP** only tasks marked [ ] (pending) or currently in progress  
- **ADD** new tasks based on current project phase and PLANNING.md requirements
- **ORGANIZE** remaining tasks by priority:
  - High Priority: Blocking issues, critical features
  - Medium Priority: Important but not blocking
  - Low Priority: Nice-to-have improvements
- **MAINTAIN** checkbox format: [ ] for pending, [IN PROGRESS] for active work
- If no active tasks remain, create brief "All Tasks Complete" summary and list optional future enhancements

### For AI_workdir/COMPLETED.md  
- **ADD** all completed tasks from TASKS.md with their outcomes and impact
- **INCLUDE** technical details of what was accomplished
- **MAINTAIN** chronological order (most recent completions first)

### For AI_workdir/PLANNING.md Integration
- **REVIEW** current plans in PLANNING.md to identify missing tasks
- **CREATE** new tasks for any active plans that lack corresponding task items
- **ENSURE** task priorities align with plan priorities

## Task Management Rules
- **Each task** must be specific and actionable
- **Use clear completion criteria** so progress can be measured
- **Break down large tasks** into smaller, manageable items
- **Link tasks to plans** when they support specific planning objectives

## Key Principle
**TASKS.md should only contain work that still needs to be done**

The goal is to maintain a clean, actionable task list that clearly shows what work remains, while preserving completed task history in COMPLETED.md for reference.
