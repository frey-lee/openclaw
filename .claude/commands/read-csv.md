# Read CSV Tool

Read and analyze CSV files using pandas with customizable options.

## Usage

This command takes a file path as an argument and displays the CSV contents.

**Example usage:**
- `/read-csv csv_sample.csv` - Read CSV from current directory
- `/read-csv "C:\path\to\file.csv"` - Read CSV with full path

Run the CSV reader script with the provided file path:
