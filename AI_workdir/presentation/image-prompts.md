# Image Generation Prompts — Nano Banana Style

Each prompt generates a slide illustration in the "nano banana" aesthetic: tiny cute banana characters in miniature diorama scenes, soft lighting, pastel colors, clean isometric or slight top-down perspective. Think tiny banana people in a tech world.

Nano banana style, pastel colors, soft lighting, miniature diorama aesthetic.
